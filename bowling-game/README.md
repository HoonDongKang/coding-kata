# 🎳 Bowling Game Kata 요구사항

## 📌 기본 규칙

-   게임은 **10프레임**으로 구성된다.
-   각 프레임은 두 번의 투구로 최대 **10핀**을 쓰러뜨릴 수 있다.
-   쓰러뜨린 핀의 개수를 점수로 기록한다.

---

## 📌 스트라이크 (Strike)

-   한 프레임에서 첫 번째 투구로 10핀을 모두 쓰러뜨린 경우.
-   해당 프레임의 점수 = 10 + **다음 프레임의 두 번의 투구 점수 합**.
-   스트라이크가 나오면 두 번째 투구 없이 프레임 종료.

---

## 📌 스페어 (Spare)

-   한 프레임의 두 번 투구 합이 10핀인 경우.
-   해당 프레임의 점수 = 10 + **다음 프레임의 첫번째 투구 점수**.

---

## 📌 일반 (Open Frame)

-   두 번의 투구 합이 10 미만인 경우.
-   해당 프레임의 점수 = 두 투구의 합.

---

## 📌 10번째 프레임 (보너스 규칙)

-   마지막 프레임에서는 보너스 투구 규칙이 적용된다.
    -   스트라이크 → **2번의 추가 투구 가능**.
    -   스페어 → **1번의 추가 투구 가능**.
-   보너스 투구는 **점수 계산에만 포함**되며 새로운 프레임으로 카운트하지 않는다.

---

## 📊 예시 점수 계산

1. **모든 투구에서 1핀씩만 쓰러뜨린 경우**

    - 20번 투구 → 총점 `20`

2. **모든 프레임 스트라이크 (Perfect Game)**

    - 12번 스트라이크 → 총점 `300`

3. **첫 번째 프레임: 스페어 (5+5), 두 번째 투구: 3핀, 나머지: 모두 0**
    - 1프레임: 10 + 3 = 13점
    - 2프레임: 3점
    - 나머지: 0점
    - 총점 = `16`

---

## 🛠️ 구현 목표 (TDD 순서)

1. `roll(pins: number): void`
    - 한 번 굴린 핀 개수를 기록한다.
2. `score(): number`
    - 전체 게임의 총 점수를 계산한다.
3. 단계별 테스트 케이스
    - 모든 투구가 0점인 경우
    - 모든 투구가 1점인 경우
    - 스페어 처리 (보너스 적용)
    - 스트라이크 처리 (보너스 적용)
    - 퍼펙트 게임 (300점)
